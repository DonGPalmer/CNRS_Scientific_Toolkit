# CNRS Scientific Toolkit v0.11.1

## Division Classification Consistency Patch

This patch corrects the legacy v0.8.x division-status API so that it agrees with the numerator-aware Gaussian-rational termination theorem already implemented in v0.11.0.

### Main correction

A power-of-five denominator is not automatically terminating because

```text
5 = (-2+i)(-2-i).
```

Termination requires cancellation of the conjugate-base factor by the numerator. Accordingly, `1/5` and `1/25` are shifted eventually periodic, while `(-2-i)/5 = 1/(-2+i)` terminates.
