# Toolkit and Programme Status Vocabulary Mapping

The Toolkit provenance registry uses implementation-oriented labels. The books and programme records use five epistemic labels. They serve different purposes and should not be conflated.

| Toolkit registry label | Programme-level interpretation |
|---|---|
| `theorem_backed` | Established within current model |
| `computationally_verified` | Established within current model, with computational evidence |
| `conditional` | Derived, conditional — awaiting full specialist review |
| `scaffold` | Usually Speculative; an implementation scaffold is not itself a physical or mathematical result |
| `bridge` | Classify individually as conditional or speculative bridge |
| `validation` | Supporting validation evidence, not a separate theorem |
| `open` | Open |

`Postulated` is a programme-level category and normally does not appear as an implementation provenance label.
