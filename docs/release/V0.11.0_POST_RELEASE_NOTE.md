# v0.11.0 post-release note

A retained legacy classifier in `cnrs.cnrs_division_status` used a denominator-only power-of-five rule inconsistent with the theorem-aligned `cnrs.division` module. In v0.11.0, callers of the legacy function could receive an incorrect terminating classification for values such as `1/5` and `1/25`.

This is corrected in v0.11.1. Users should not rely on `cnrs.cnrs_division_status.classify_division` from v0.11.0 for denominators divisible by five.
