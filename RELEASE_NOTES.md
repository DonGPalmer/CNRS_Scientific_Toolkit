# Release Notes

## Current release

This release provides a unified CNRS Scientific Toolkit source package for GitHub use.

Highlights:

```text
CNRS-A finite complex-base representation
CNRS-float approximate complex representation
Gaussian rational support, including periodic and Laurent-periodic cases
CnrsComplex scientific interface
CNRS-H coefficient calculus
CNRS-H linear ODE solvers
Branch-aware complex-state helpers
Observation-map utilities
Scale-law fitting and differentiation
Three-workflow scientific comparison examples
Pytest suite with 260 passing tests and 6 expected limitation markers
```
